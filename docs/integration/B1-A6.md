# Contrato de Integración: Analytics (Célula B1) <-> Células A6 / C6

## 1. Información General
- **Módulo:** Analytics - Central Tendency
- **Responsable de Contrato:** Hugo Mendoza (Célula B1)
- **Versión:** 1.0.0

## 2. Especificación de Endpoints

### Endpoint 1: Cálculo por Sección
- **Método:** `GET`
- **URL:** `/api/v1/analytics/sections/{id}/central-tendency`

### Endpoint 2: Cálculo por Curso
- **Método:** `GET`
- **URL:** `/api/v1/analytics/courses/{id}/central-tendency`

### Parámetros de Ruta
| Parámetro | Tipo | Requerido | Restricciones | Descripción |
|---|---|---|---|---|
| `id` | numérico | Sí | `id > 0` | Identificador único de la sección o curso. |

### Códigos de Respuesta HTTP Esperados
| Código | Estado | Escenario de Disparo |
|---|---|---|
| **200** | `OK` | El cálculo se realizó correctamente con los datos obtenidos. |
| **400** | `Bad Request` | El `{id}` es negativo, cero, o contiene texto/símbolos. |
| **404** | `Not Found` | El `{id}` consultado no existe en la base de datos. |
| **500** | `Internal Server Error` | Fallo inesperado en el motor de cálculo o servidor. |
| **502** | `Bad Gateway` | La API de Analytics no pudo comunicarse con el microservicio de persistencia/datos. |
